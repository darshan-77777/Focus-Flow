# FocusFlow

FocusFlow is a student productivity web app built using HTML, CSS and JavaScript.

It helps students manage study tasks, track coding hours and stay consistent with daily goals.

## Features

- Add daily study tasks
- Complete and delete tasks
- Save tasks using Local Storage
- Study streak tracker
- Study progress bar
- Coding hours tracker
- 25 minute study timer
- Reset timer functionality
- Motivation quote generator
- Dark mode support
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Future Improvements

- User login system
- Calendar integration
- Monthly analytics
- Custom study categories
- Mobile app version
